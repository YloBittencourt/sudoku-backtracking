Raio-X do algoritmo

    Como funciona

    resolver(tabuleiro):
  célula ← próxima célula vazia
  se não há célula: return SUCESSO
  para v em 1..9:
    se v é válido em célula:
      célula ← v                 // tenta
      se resolver(tabuleiro): return SUCESSO
      célula ← 0                 // backtrack
  return FALHA

    Backtracking explora a árvore de decisões em profundidade e desfaz a última escolha ao chegar a um beco sem saída. Compare o modo ingênuo com a heurística MRV no puzzle “difícil”: o número de tentativas cai drasticamente.

    Desafio PAA: variante do trabalho original em C (../core/sudoku.c): a diagonal de cada bloco 3×3 forma um palíndromo único (fase 1) e o restante do bloco é preenchido com no máximo um par repetido (fase 2).
